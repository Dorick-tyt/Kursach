# Финансовый трекер

Проект для анализа банковских транзакций с функциями отчетов, поиска и главной страницы.

## Главная страница `views.py`

Функция для отображения главной страницы с приветствием, информацией по картам, топ-5 транзакциями, курсами валют и ценами акций.

## Отчеты `reports.py`

Функции для формирования отчетов по транзакциям за последние 3 месяца.

### Особенности:

* Все отчеты автоматически сохраняются в JSON файлы в папку reports/

* Данные фильтруются за последние 90 дней от указанной даты

* Используется декоратор `@report_decorator()` для сохранения результатов

## Простой поиск `services.py`

Функция для поиска транзакций по описанию или категории.

### Тестирование

Модули сопровождаются набором тестов, которые можно проверить с помощью следующих команд:

* Запуск всех тестов `uv run pytest`

* Запуск с отчетом о покрытии кода uv run pytest --cov=tests --cov-report=html
